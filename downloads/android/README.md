# Emissor Android

[Baixar Varthex Licenças 1.0.1](https://github.com/arthurtvrs10/Varthex-Orders/releases/download/android-v1.0.1/Varthex-Licencas-1.0.1.apk) · [SHA-256](Varthex-Licencas-1.0.1.apk.sha256)

Android 8.0 ou superior. Emissão offline de licenças de 1, 2, 3 meses ou vitalícias para o Varthex Comanda.

Este app é para o responsável pelas licenças. O APK não contém a chave privada: importe o arquivo PEM do emissor original ou use **Colar chave privada** para colar seu conteúdo completo.
