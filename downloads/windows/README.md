# Varthex Comanda 1.2.1

[Baixar instalador para Windows x64](VarthexComanda-1.2.1-Setup-win-x64.exe?raw=true) · [SHA-256](VarthexComanda-1.2.1-Setup-win-x64.exe.sha256)

Esta versão aplica a identidade visual aprovada: logo no cabeçalho, paleta grafite e laranja, novos estilos de botões, ícone do aplicativo e crédito “Desenvolvido pela Varthex”.

Feche o aplicativo e execute o instalador para atualizar. O runtime .NET está incluído; a instalação é por usuário e mantém os dados e a licença existentes.

O instalador não possui assinatura de código. Esta distribuição está versionada no repositório; a publicação de uma release no GitHub é feita separadamente.
