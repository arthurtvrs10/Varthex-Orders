# Guia do operador — Varthex Comanda

O programa **anota o que cada cliente consumiu e mostra o total**. Ele **não cobra**: quem cobra é a maquininha. Você digita o valor na maquininha e só depois confirma no programa.

## No dia a dia

1. **Abrir uma comanda.** Em **Atendimento**, digite o número da comanda e aperte `Enter` (ou clique no número livre na grade). Se o número já estiver aberto, o programa apenas mostra a comanda que já existe.
2. **Adicionar um produto.** Clique no produto, ou aperte `Ctrl+F`, digite parte do nome e aperte `Enter` (entra o primeiro da lista). Repetir o mesmo produto aumenta a quantidade.
3. **Corrigir a quantidade.** Clique em **+** ou **−** no item. Com o item marcado, as teclas `+` e `-` fazem o mesmo. Se a quantidade for 1 e você diminuir, o programa pergunta se quer tirar o item.
4. **Ver o total.** O **TOTAL DA COMANDA** fica sempre à vista. Confira os itens com o cliente.
5. **Digitar na maquininha.** Clique em **Finalizar comanda** (ou aperte `F4`). A tela mostra **"Total a pagar"** e o pedido "Digite este valor na maquininha". Digite esse valor na maquininha.
6. **Marcar que foi aprovada.** Só depois que a maquininha **aprovar**, marque **"A cobrança foi aprovada fora do sistema?"** e clique em **Confirmar e encerrar**. O número fica livre para o próximo cliente.
7. **Se a maquininha falhar ou o cliente desistir:** **não marque nada**. Clique em **Voltar para a comanda** (ou aperte `Esc`). A comanda continua aberta, com tudo como estava, e nada é cobrado nem registrado como venda.

Para desistir de uma comanda inteira, use **Cancelar comanda** (o programa pede confirmação; a comanda é anulada e o número fica livre).

## Atalhos

| Tecla | O que faz |
| --- | --- |
| `Ctrl+N` | Vai para o campo do número da comanda |
| `Ctrl+F` | Vai para a busca de produto |
| `Enter` | Abre a comanda digitada (ou mostra a que já está aberta); na busca, adiciona o primeiro produto |
| `+` / `-` | Aumenta / diminui a quantidade do item marcado |
| `↑` / `↓` | Marca o item anterior / seguinte |
| `F4` | Finalizar comanda (tela do total) |
| `Esc` | Voltar |
| `Ctrl+1` a `Ctrl+5` | Atendimento, Produtos, Histórico, Backup, Configurações |

Cuidado: nas perguntas de confirmação, apertar `s` responde **Sim**.

## Backup (cópia de segurança)

O programa faz cópias sozinho ao abrir no dia e ao fechar. Para **copiar para o pendrive**: tela **Backup**, com o pendrive ligado, clique em **Escolher pasta externa e criar backup...** e escolha uma pasta do pendrive. Faça isso **no fim do dia**. Se o programa disser que não conseguiu acessar a pasta, confira se o pendrive está encaixado.

## Se aparecer o aviso "O banco de dados está corrompido"

O programa abre só na tela **Backup**, com uma faixa vermelha: **"Restaure um backup para continuar"**. Significa que o arquivo de dados foi danificado (por exemplo, por queda de energia no meio de uma gravação). **Não desligue nem apague nada.** Escolha o backup mais recente na lista, clique em **Restaurar backup selecionado**, confirme, e o programa reinicia sozinho. As comandas e vendas feitas depois desse backup não estarão lá; chame quem cuida do sistema se tiver dúvida antes de restaurar.

## Se o programa fechar de repente ou faltar luz

Abra de novo. As **comandas que estavam abertas voltam** com os mesmos itens e total. Vendas já encerradas continuam no **Histórico**.

## Se aparecer "O Varthex Comanda já está aberto"

Ele já está aberto neste computador (procure na barra de tarefas). Só pode haver um de cada vez.
